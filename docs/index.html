How to Install

Easy 1-minute manual installation until official marketplace publication

Option A

VS Code Installation

  1. Download the extension using the Download for VS Code button above.
  2. Open VS Code and press Ctrl+Shift+X (Extensions view).
  3. Click the ... (Views and More Actions) menu in the top-right corner.
  4. Select Install from VSIX... and choose the downloaded file.
Option B

JetBrains IDE Installation

  1. Download the plugin using the Download for JetBrains button above.
  2. Open your IDE (IntelliJ, WebStorm, PyCharm, etc.).
  3. Open Settings / Preferences (Ctrl+Alt+S or Cmd+,).
  4. Go to Plugins, click the ⚙️ gear icon, and select Install Plugin from Disk....
Option C

Configure Your AI Agent

  1. Add review-hub to your AI tool MCP config (~/.claude.json, Cline, Roo Code):
    "command": "npx", "args": ["-y", "review-hub-mcp"]
  2. Click Copy AI Agent Rules in Review Hub to add enforcement rules into CLAUDE.md, .cursorrules, or .clinerules.

Frequently Asked Questions

Everything you need to know about Review Hub

🔒 Does Review Hub send my code to the cloud?

No, never. Review Hub runs 100% locally on your machine. All changes, baselines, and diffs are kept in a local SQLite store (~/.review-hub/hub.db). No telemetry, no external server.

🤖 Which AI coding agents are supported?

Works with any tool that supports MCP (Claude Code, Cursor, Cline, Roo Code, Antigravity, Windsurf, etc.). Even if an AI writes directly via shell, our watcher intercepts it.

⚡ Can I use VS Code and JetBrains together?

Yes! Review Hub's local hub server coordinates across multiple IDE windows. Changes proposed in one editor update instantly across all open windows.

🛡️ What if the AI refuses to call MCP?

Click Copy AI Agent Rules in the Review Hub toolbar and paste the rules into CLAUDE.md or .cursorrules. You can also disable native write tools in Cline / Roo Code settings.
