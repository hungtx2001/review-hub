Get Started in 2 Steps

Connect your JetBrains IDE to any AI coding assistant in seconds.

1

Install Review Hub in IDE

Open your JetBrains IDE and install directly from the Marketplace:

Shortcut Ctrl+Alt+S / ⌘,
1. Plugins → Marketplace tab
2. Search "Review Hub"
3. Click Install • No restart needed
Embedded MCP starts automatically on port 49182
2

Connect AI Agent (MCP)

Add to your agent's config (claude.json, cline_mcp_settings.json): 

{
  "mcpServers": {
    "review-hub": {
      "url": "http://127.0.0.1:49182/sse"
    }
  }
}
